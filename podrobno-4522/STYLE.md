# Единые требования к снимкам

Все снимки каталога должны выглядеть как одна серия: один фон, один свет, один ракурс. Тогда сотни тысяч
карточек на сайте смотрятся аккуратно, а снимок группы подходит ко всем ее позициям.

## Обязательно

| Параметр | Требование |
|---|---|
| Стиль | фотореализм, предметная (студийная) съемка для каталога; не рисунок, не 3D-мультяшность |
| Фон | бесшовный светлый нейтральный **#F4F6F9**, без текстуры, горизонта, виньетки и градиентов |
| Свет | мягкий студийный из большого софтбокса, без пересветов и жестких бликов |
| Тень | мягкая контактная тень под предметом (предмет не «висит в воздухе») |
| Ракурс | 3/4, немного сверху; предмет целиком, по центру, занимает около 70 % кадра |
| Резкость | по всему предмету |
| Формат | квадрат **1200×1200 px**, **WebP**, качество около 82, размер файла **не больше 200 КБ** |
| Имя файла | `<код>.webp` — код из таблицы (например `F00001.webp`) |
| Цвет | sRGB, без цветокоррекции «под настроение»; цвета изделия — как в описании |

Кабель: отрезок 30–40 см по диагонали кадра, разделанный конец ближе к камере, разделка ступенькой
(оболочка → броня/экран, если есть → изолированные жилы → зачищенные концы жил 10–15 мм).

## Запрещено

- чужие логотипы, товарные знаки, названия заводов и брендов, заводская маркировка на изделии;
- водяные знаки, подписи, любой текст, цифры и надписи в кадре (на кабеле — без печатной маркировки);
- люди, руки, лица;
- лишние предметы, реквизит, интерьер, второй экземпляр изделия;
- коллажи, рамки, тени-«подложки», обтравка с белыми ореолами;
- копирование чужих фото один в один (в том числе img2img «под копирку») — снимок должен быть своим.

## Проверка готового кадра

Перед сдачей сверьте снимок с колонкой «Описание RU»:

1. **Число видимых элементов**: число жил у кабеля (нейросети часто ошибаются — пересчитайте на срезе), полюсов
   у автомата, ручьев у ремня, рядов шариков у подшипника.
2. **Конструкция**: есть ли экран, броня, уплотнения, фланец, лапы — ровно как в описании.
3. **Цвета**: оболочка, изоляция жил (раскраска), корпус.
4. **Пропорции и масштаб**: тонкий кабель не должен выглядеть как силовой, узкий подшипник — как широкий.
5. **Нет текста, логотипов, людей**; фон #F4F6F9; квадрат 1200×1200; WebP ≤ 200 КБ.

Если хотя бы один пункт не выполнен — кадр не принимается.

## Готовые тексты

У каждого кадра в таблице есть: «Описание RU» (подробно для человека или генератора), «Промпт EN» (тот же смысл
на английском), «Негатив EN / RU» (чего быть не должно). Описание уже включает фон, свет, ракурс и запреты —
их не нужно дописывать.
